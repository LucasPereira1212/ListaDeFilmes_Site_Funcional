Nesse projeto temos um site de lista de filmes, aonde pode-se escolher o filme que você quiser para adicionar.

**ATENÇÃO**: A pesquisa do filme deve ser feita em english.

Temos validação de campos para caso não for encontrado nada, e támbem validação de ano, porém o ano não é obrigatório
